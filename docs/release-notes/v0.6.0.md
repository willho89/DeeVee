First public release of **DeeVee**, a DVD-Video player core for RetroArch, rewritten from scratch. It replaces the earlier, abandoned attempt that used to live in this repository.

> **Alpha.** It plays real discs end to end, but has been tested on a handful of discs and mostly on one machine (a Steam Deck). Reports are welcome, especially from Windows, macOS, Android and Raspberry Pi users.

## Highlights

- **Full disc menus.** The disc's own program runs as written: First Play, root/title/chapter/audio/subtitle menus, timed and infinite stills, motion menus with audio and auto-action buttons. Highlights are drawn the way the disc defines them. You can navigate with the RetroPad, a mouse or touch.
- **Any region.** The player's region is picked from the disc, which also passes region checks (RCE) inside the disc's menus. You can force a region instead.
- **ISO, CHD and VIDEO_TS.** `.iso` images, DVD `.chd` images (`chdman createdvd`) and `VIDEO_TS` folders.
- **Video:** MPEG-1/2, NTSC and PAL, 4:3 and anamorphic 16:9, 3:2 pulldown, and deinterlacing (bwdif/yadif at field rate).
- **TV Display Type:** 16:9, 4:3 Letterbox or 4:3 Pan & Scan, like a hardware player's setup menu. It respects the disc's permitted display modes and uses its 4:3 menu and subtitle variants.
- **Audio:** AC-3, DTS, LPCM and MPEG audio, downmixed to stereo or Dolby Pro Logic II, with optional dynamic range compression.
- **Subtitles:** on, off or disc default, a preferred language, and forced subtitles always shown.
- **Playback controls:** seek, pause, chapter skip, hold-to-scan, audio/subtitle/angle cycling and an info display.
- **Save states as resume points.** A save state stores where you are and what the disc's program has remembered. Resuming brings back the same picture or menu button, and the disc then carries on exactly as it would have.
- **RetroArch Restart** starts the disc over from its startup program.

Each zip contains the core, `deevee_libretro.info` and `INSTALL.txt`. Put the core in RetroArch's `cores` folder and the `.info` file in its `info` folder. On Android, use *Load Core → Install or Restore a Core* instead.

## Encrypted discs

DeeVee doesn't include CSS decryption. Decrypted rips, such as MakeMKV ISOs, play as they are. For CSS-encrypted images, put **libdvdcss** in RetroArch's **system** folder, the same place BIOS files go: `libdvdcss.so.2` on Linux and Android, `libdvdcss-2.dll` on Windows, `libdvdcss.2.dylib` on macOS. Without it, an encrypted disc stops with an on-screen message naming the file it needs.

## Testing status

- **Test suite:** passes on Linux x86_64, Windows (under Wine), macOS arm64 and macOS x86_64 in CI, and on Linux arm64/armhf under QEMU.
- **Menu navigation:** checked against VLC button by button on a disc with 14 menus (about 100 paths). Three bugs were found that way, and all are fixed.
- **Not yet verified:**
  - CSS decryption on a genuinely encrypted image.
  - Real PAL discs, multi-angle discs, and discs with separate menus per TV type.
  - Android on a real device. The Android cores build, but nobody has run them yet.
  - Windows outside Wine, and real Raspberry Pi hardware.
- **Not supported:** physical DVD drives, Blu-ray and DVD-Audio.
